# Компиляция проекта

- через GNU make: `mk/all.mk`:

```sh
make all
ls -la bin
```
```
cql -> cql_pc_dponyatov_251027
```

- `mk/rule.mk`
```Makefile
bin/$(BINFILE): $(C) $(H) $(CP) $(HP) $(MK) $(CM)
	cmake --fresh --preset linux
	cmake --build --preset linux -j
```

- чистая сборка: сначала зачистить каталог сборки cmake:
```sh
cmake --fresh --preset linux
```
- запустить cmake вручную:
```sh
cmake --build --preset linux -j
```

- через VSCode:
	- Ctrl+Shift+P
		- CMake: Delete Cache and Reconfigure
	- Ctrl+Shift+P
		- CMake: Clean Rebuild
