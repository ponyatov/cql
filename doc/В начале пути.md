# 1.4. В начале пути

## 1.4.1. [[Здравствуй параллельный мир]]

```cpp
#include <iostream>
#include <thread>

void hello() { std::clog << "Hello\n"; }

int main(int argc, char *argv[]) {
    arg(0, argv[0]);
    //
    std::thread t(hello);
    std::this_thread::yield();
    //
    for (int i = 1; i < argc; i++) {
    }
    //
    t.join();
    return 0;
}
```

- [[Cpp/thread]]
- `hello()`
	- в каждом потоке должна быть начальная функция, в которой начинается исполнение потока
- [[Cpp/join]]
	- Если бы main() не ждал завершения нового потока, то просто дошел бы до конца, после чего исполнение программы закончилась бы – быть может, еще до того, как у нового потока появился шанс начать работу
