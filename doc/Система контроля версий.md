# [[git/git|git]]
## Система контроля версий

- управление версиями кода
- синхронизация работы внутри группы разработчиков

1. Создайте **свой форк** проекта: https://github.com/ponyatov/cql
2. Установка минимально-необходимого набора утилит на Ubuntu/Debian

```sh
sudo apt install git make curl
```

3. Клонирование вашего репозитория и создание рабочей ветки
```sh
git clone -o gh git@github.com:yourname/cql.git ~/cql
cd ~/cql
git checkout -b yourname
git push -uv gh yourname
```
