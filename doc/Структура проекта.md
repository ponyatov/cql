# Структура проекта

```
cql/
	.vscode/     локальные/рекомендованные настройки VSCode
	bin/         целевой каталог установки исполняемых (бинарных) файлов
	doc/         документация
		html/    сгенерированная doxygen
	lib/         скрипты и 
		cql.ini  инициализационный файл
	inc/         заголовочные файлы (.hpp)
	src/         файлы исходного кода (.cpp)
	tmp/         каталог для временных файлов
	db/          хранище локальной БД
```
```
	mk/                \ скрипты GNU Make
	Makefile           /
	cmake/             \ скрипты сборки CMake
	CMakeLists.txt
	CMakePresets.json  /
```
```
.clang-format
.prettierc
```
```
doc/DoxygenLayout.xml
doc/logo.png
.doxygen
```
