# Среда разработки
## [[vscode/VSCode|VSCode]] с расширениями С++

1. Скачать пакет для вашего дистрибутива:
	- https://code.visualstudio.com/download
2. Установить скачанный пакет:
```sh
sudo dpkg -i ~/Downloads/code_1.105.1-1760482543_amd64.deb
sudo apt --fix-broken install
```
3. Запустить [[vscode/VSCode|VSCode]] указав `~/cql` в качестве проекта
4. Согласиться с установкой рекомендованных проектом расширений (`.vscode/extensions.json`)
