# [[Cpp/Основы C++|Основы C++]]

**Цель**: Создать базовый каркас `cql` с консольным интерфейсом

[[Cpp/C++|C++]] — это компилируемый статически типизированный язык программирования общего назначения, поддерживающий различные парадигмы: процедурное, объектно-ориентированное, обобщенное и (крайне ограниченное) функциональное программирование. Изучение основ C++ является фундаментальным для понимания принципов системного программирования и разработки высокопроизводительных приложений (особенно если вы разрабатываете ПО для встроенных систем, или микроконтроллеров).
