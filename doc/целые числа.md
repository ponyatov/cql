# целые числа

Целые числа являются фундаментальным типом данных в разработке программного обеспечения, и доступны в любых нормальных языках программирования (кроме укурков, разработавших JavaScript).

C++ предоставляет несколько целочисленных типов, различающихся по размеру и диапазону значений. Эти типы деляется на 
- классические, и
	- (битовый размер размер которых в общем случае зависит от платформы)
- [[stdint]]
	- (явно задают размер и наличие знака в имени типа)

## Модификаторы знака

- классический целый тип может быть с модификатором:
	- **`signed`** - знаковый (отрицательные и положительные значения)
	- **`unsigned`** - беззнаковый (только неотрицательные значения)
- stdint
	- префикс `i` - знаковый: `int32_t`
	- префикс `u` - беззнаковый: `uint8_t`

## Диапазоны значений

Диапазоны значений зависят от архитектуры системы, но типичные значения для 32-битных систем:

|Тип|Размер|Диапазон (знаковый)|Диапазон (беззнаковый)|
|---|---|---|---|
|`char`|1 байт|-128 до 127|0 до 255|
|`short`|2 байта|-32,768 до 32,767|0 до 65,535|
|`int`|4 байта|-2,147,483,648 до 2,147,483,647|0 до 4,294,967,295|
|`long long`|8 байт|-9.2×10¹⁸ до 9.2×10¹⁸|0 до 1.8×10¹⁹|

## Объявление и инициализация

```cpp
// Различные способы объявления целых чисел
int age = 25;
unsigned int population = 8000000;
short temperature = -15;
long bigNumber = 123456789L;
long long veryBigNumber = 123456789012345LL;

// Использование автоматического вывода типа
auto count = 10;        // int
auto flags = 255U;      // unsigned int
auto distance = 100L;   // long
```

## Литералы целых чисел

```cpp
int decimal = 100;       // десятичная система
int octal = 0144;        // восьмеричная (начинается с 0)
int hexadecimal = 0x64;  // шестнадцатеричная (начинается с 0x)
int binary = 0b1100100;  // двоичная (C++14 и выше)

// Суффиксы для указания типа
auto a = 42U;    // unsigned int
auto b = 42L;    // long
auto c = 42LL;   // long long
auto d = 42UL;   // unsigned long
```

## Арифметические операции

Для целых чискл поддерживаются все основные арифметические операции:

```cpp
int a = 10, b = 3;

// Базовые операции
int sum = a + b;        // 13
int difference = a - b; // 7
int product = a * b;    // 30
int quotient = a / b;   // 3 (целочисленное деление!)
int remainder = a % b;  // 1 (остаток от деления)

// Инкремент и декремент
a++;    // постфиксный инкремент: 11
++a;    // префиксный инкремент: 12
b--;    // постфиксный декремент: 2
--b;    // префиксный декремент: 1
```

### Целочисленное деление

При делении целых чисел дробная часть отбрасывается:

```cpp
int result1 = 7 / 2;   // 3, а не 3.5
int result2 = -7 / 2;  // -3 (округление в сторону нуля)
```

### Переполнение

При выходе за границы диапазона происходит переполнение:

```cpp
unsigned int max_uint = 4294967295U;
max_uint += 1;  // 0 (переполнение беззнакового типа)

int max_int = 2147483647;
max_int += 1;   // неопределенное поведение для знакового типа
```

## Преобразования целых типов

### Неявное преобразование

```cpp
int small = 100;
long large = small;     // безопасное расширение до бОльшего типа

long big = 1000000000L;
int small2 = big;       // возможна потеря данных!
```

### Явное преобразование ([[кастинг]])

```cpp
double pi = 3.14159;
int intPi = static_cast<int>(pi);  // 3

int x = 100;
unsigned int y = static_cast<unsigned int>(x);
```

## Практические рекомендации по выбору целого типа

- Используйте `int` по умолчанию для целых чисел
- Для неотрицательных значений используйте `unsigned`
- Для больших чисел используйте `long long`
- Для экономии памяти в массивах используйте `short` или `char`
- Для описания форматов хранения и обмена данных используйте [[stdint]] с явным указанием каждого поля данных в битах (в этом случае обеспечивается переносимость кода между 8- 16- 32- битными микроконтроллерями и 64-битными встраиваемыми, мобильными устройствами и ПК)

Понимание целочисленных типов и их особенностей критически важно для написания корректного и эффективного кода на C++, особенно в таких областях как разработка баз данных и системное программирование.
