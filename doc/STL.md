# Стандартная библиотека (STL)

Стандартная библиотека шаблонов предоставляет богатый набор готовых компонентов:

- **Контейнеры**: `vector`, `map`, `set`, `list`
- **Алгоритмы**: сортировка, поиск, модификация данных
- **Итераторы**: унифицированный доступ к элементам контейнеров
- **Строки**: класс `string` для удобной работы с текстом
