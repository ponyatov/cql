# 2.1.1. Запуск потока

следует сконструировать объект std::[[Cpp/thread|thread]], который определяет, какая задача будет исполняться в потоке

- задача представляет собой обычную функцию без параметров, возвращающую void
- функция, который принимает дополнительные параметры 
	- и выполняет ряд независимых операций, 
	- информацию о которых получает во время работы от той или иной системы передачи сообщений
	- останавливается такой поток, 
		- [[Cpp/return|return]]
		- когда получит соответствующий сигнал, опять же с помощью системы передачи сообщений

```cpp
void do_some_work();
std::thread my_thread(do_some_work);
```

класс std::thread работает с любым типом, допускающим вызов ([[Cpp/Callable]]), поэтому конструктору std::thread можно передать экземпляр класса, в котором определен оператор вызова:
