# Основы работы с памятью

C++ предоставляет прямой доступ к управлению памятью через операторы `new` и `delete`. Однако современный C++ рекомендует использовать умные указатели и контейнеры STL для автоматического управления ресурсами, что снижает вероятность утечек памяти и других ошибок.
