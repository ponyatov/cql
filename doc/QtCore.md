# [[Qt/QtCore|QtCore]]
## является базовым для всех остальных модулей

**[[cql/QtCore|QtCore]]** — это фундаментальный модуль [[Qt]], содержащий базовые классы, которые используются всеми другими модулями. Он предоставляет основные функции, не связанные с графическим интерфейсом.

- является базовым для всех приложений
- не содержит классов, относящихся к интерфейсу пользователя
- если вы пишете сервеное или консольное приложение, то, вполне возможно, вы можете ограничиться одним этим модулем

входят более 200 классов:

## Базовые классы

- корневой класс [[QObject]], являющийся краеугольным камнем всей объектной модели [[Qt]]
	- базовый класс событий [[QEvent]]
- [[QVariant]] — универсальный контейнер для типов данных
	- контейнерные классы [[QList]], [[QVector]], [[QMap]]
- [[QString]] — работа со строками Unicode

## События и таймеры

- базовый класс событий [[QEvent]]
- классы для работы с таймером [[QBasicTimer]] и [[QTimer]]
- классы для работы с датой и временем [[QDate]] и [[QTime]]

## Файлы и данные

- классы для ввода и вывода [[QIODevice]], [[QTextStream]], [[QFile]]

## Процессы

- классы процесса [[QProcess]]
	- для программирования многопоточности: [[QThread]], [[QWaitCondition]], [[QMutex]]

## Приложения

- класс приложения [[QCoreApplication]], из объекта которого, если требуется, можно запустить цикл событий.
	- класс для сохранения настроек приложения [[QSettings]]
