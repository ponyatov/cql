# Архитектура [[Qt]]

[[Qt]] — это не просто библиотека виджетов, это **кросс-платформенный фреймворк** для разработки приложений на C++. Его архитектуру можно представить как многослойный пирог, где каждый уровень предоставляет свой набор функциональностей.

- **Model-View-Controller ([[MVC]]) и его вариации ([[oop/MVD|Model-View-Delegate]]):** Это основа для построения UI. Модель управляет данными, View отвечает за отображение, а Delegate — за отрисовку элементов и редактирование. Это обеспечивает четкое разделение логики данных и их представления.
