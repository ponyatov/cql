# Введение в [[Qt]]

**[[Qt]]** — это кроссплатформенный фреймворк для разработки программного обеспечения на языке [[Cpp/C++|C++]]. Он широко используется для создания графических интерфейсов ([[gui/GUI|GUI]]), но также предоставляет богатый набор возможностей для работы с сетью, базами данных, многопоточностью и многое другое.
