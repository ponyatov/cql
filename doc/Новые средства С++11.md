# Новые средства С++11

В 2011 году комитет по стандартам C++ выпустил новую основную версию стандарта ISO C++. Этот пересмотренный стандарт является последним этапом развития языка C++, его основное внимание уделено эффективности программирования

- [[Cpp/auto|auto]] для выведения типов
- интеллектуальные указатели и 
- контейнеры с поддержкой перемещения
