# 6. Функции [[Cpp/C++|C++]]

Функции в C++ являются основными строительными блоками программы. Они обеспечивают модульность и повторное использование кода. Функция состоит из:

- Прототипа (объявления)
	- обычно в заголовочных файлах .hpp
- Тела функции (определения)
	- реализация в .cpp
- Параметров и возвращаемого значения
	- указываются и объявлении, и в реализации

Передача параметров может осуществляться 
- **по значению**, 
- **по ссылке** или 
- через [[указатели]], 

что предоставляет гибкость в управлении памятью и производительностью.
