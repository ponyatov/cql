# Типы данных [[С++]]

C++ предоставляет богатую систему типов, включающую:

- **Базовые типы**: 
	- целые числа: `int`, `short`, `long`
	- числа с плавающей запятой: `float`, `double`,
	- текстовые символы и строки: `char`, `char[]`, `std::string`
	- `bool = true|false`
- **Модификаторы целых типов**: `signed`, `unsigned`, 
- **[[Составные типы]]**: массивы, структуры, объединения, перечисления
- **[[cql/Указатели и ссылки|Указатели и ссылки]]**: для работы с памятью и псевдонимами переменных

Каждая переменная должна быть объявлена с указанием типа перед использованием, что обеспечивает статическую проверку типов на этапе компиляции.
