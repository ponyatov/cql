# Куча и стек
## heap / stack

## Стек

**Стек** - это область памяти, которая управляется автоматически. Здесь хранятся:

- Локальные переменные функций
- Параметры функций
- Временные объекты

**Преимущества стека:**

- Быстрое выделение и освобождение памяти
- Автоматическое управление временем жизни
- Кэш-дружественность

**Ограничения:**

- Ограниченный размер (обычно 1-8 МБ)
- Время жизни привязано к области видимости

```cpp
void exampleStack() {
    int localVar = 42;          // Выделяется в стеке
    double array[100];          // Массив в стеке
    std::string localString;    // Объект string в стеке
    
    // Память автоматически освобождается при выходе из функции
}
```

## Куча

**Куча** - это динамическая область памяти, управляемая программистом вручную.

**Особенности кучи:**
- Большой размер (ограничен только системой)
- Время жизни контролируется программистом
- Более медленное выделение/освобождение
- Потери на служебные поля на каждый выделенный элемент в куче

```cpp
void heapExample() {
    int* dynamicInt = new int(42);    // int в куче
    double*     arr = new double[10]; // массив в куче
    
    delete   dynamicInt;          // обязательно освободить!
    delete[] arr;                 // для массивов свой синтаксис
}
```
