# Управляющие конструкции

Язык предоставляет стандартный набор конструкций для управления потоком выполнения:

- **Условные операторы**: `if-else`, `switch-case`
- **Циклы**: `for`, `while`, `do-while`
- **Операторы перехода**: `break`, `continue`, `return`

Эти конструкции позволяют реализовывать сложную логику и алгоритмы обработки данных.
