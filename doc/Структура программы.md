# Структура программы

Базовая программа на C++ состоит из функций, основной из которых является `main()` — точка входа в приложение. Простейшая программа выглядит следующим образом:

- `src/minimal.cpp`

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

Директива `#include` подключает заголовочные файлы, в данном случае библиотеку ввода-вывода.

Функция `main()` возвращает целочисленное значение, где 0 означает успешное завершение.

## заголовочные файлы

- `inc/minimal.hpp`
```cpp
#pragma once
#include <iostream>   /// библиотечные #include выносятся в .hpp
extern int main();    /// декларация функции main()
```
- `src/minimal.cpp`
```cpp
#include "minimal.hpp" // в файлах кода используется прикладные хедеры

/// реализация функции main()
int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```
